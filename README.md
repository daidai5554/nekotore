# ねこトレ

家にある筋トレ道具・身長・体重・目標から、猫のトレーナー「にゃんだ」がメニューを組んでくれるスマホ向け筋トレアプリ（PWA）。

## ファイル
- `index.html` … アプリ本体（HTML/CSS/JS を1ファイルにまとめたもの）
- `manifest.json` / `sw.js` / `icon.svg` … ホーム画面に追加・オフライン起動用
- `dist/nekotore.html` … claude.ai Artifact 公開用（`node tests/tools/build.js` で作る）
- `tests/` … 自動テスト一式と調整ツール

## スマホで使う（自分のサイトとして公開する場合）
HTTPS の静的ホスティング（GitHub Pages / Netlify / Cloudflare Pages など）にこのフォルダの中身を置くだけで動きます。
スマホで開いて「ホーム画面に追加」すると、アプリのように全画面で起動します。

## メニューの組み方と根拠
| 項目 | 内容 | 根拠 |
|---|---|---|
| 分け方 | 週2〜3回=全身、4回=上半身／下半身、5〜6回=押す・引く・脚 | 同じ部位は48時間あける（ACSM） |
| 回数・セット | 筋肥大 8〜12回×3〜4、減量 12〜15回、健康 10〜15回。「あと1〜3回できる」ところで止める | ACSM・NSCA |
| 休憩 | 重いバーベル種目は90〜150秒、単関節種目は短め | NSCA（高重量は2分以上） |
| 種目の順番 | 多関節 → 単関節 → 体幹・バランス → 有酸素 | ACSM |
| 週のセット数 | 筋肥大は主要部位で週10〜20セットを目安として表示 | Schoenfeld ら（2017） |
| 痛みへの配慮 | 膝・腰・肩・手首ごとに禁止種目を固定（テストで保証） | 一般的な運動指導 |
| 体格・年齢 | BMI30以上・65歳以上は自重種目を1段階やさしく。60歳以上はバランス運動を追加 | ACSM（高齢者） |
| 重さの初期値 | 体重比の表＋Epley 式で目標回数に合わせる。標準体重で計算 | Epley 式 |
| 負荷の上げ方 | ダブルプログレッション（1セット目で上限、以降は疲労で1回少なくても可）。1段階が1割を超えるときは先に回数を増やす。2回続けて下限未満なら1割下げる | 一般的な指導法 |
| 消費カロリー | 筋トレは休憩込みの平均METs、有酸素は動作中のみ。60歳以上は×0.77 | 2024 Adult / Older Adult Compendium（pacompendium.com で値を確認済み） |
| たんぱく質 | 運動する人 1.4〜2.0g/kg（筋肥大は2.2gまで） | 国際スポーツ栄養学会（2017） |
| 体重ペース | 減量 0.5〜1%/週、増量 0.25〜0.5%/週 | 一般的な目安 |

## お手本アニメーション
- 68種目すべてに、正しいフォームの動き・リズム（例：しゃがむ2秒→立つ1秒）・呼吸（吐く／吸う）・注意点とよくある間違いを表示
- 体の比率は Drillis & Contini の身長比。手足の位置は逆運動学（IK）で床や道具に正しく接するように計算
- 「いっしょにやる」でリズムに合わせて回数を数える（左右がある種目は右→左）。音声ガイドあり

## RPG要素
- あなた：経験値・レベル・称号、能力4種（ちから／ふんばり／バランス／スタミナ）、実績10種
- バトル：トレーニング1回＝モンスター1体。セットごとにダメージ。5回に1回ボス
- にゃんだ：なかよし度＝猫のレベル（経験値ボーナス）。装備24種で強くなるが、戦闘には一切参加しない

## テスト
```
node tests/run_all.js
```
| テスト | 確かめていること |
|---|---|
| motion | お手本が床にめりこまない・接地点がすべらない・重心が足の上・関節が逆に曲がらない・道具を突き抜けない |
| angles | キーポーズの関節角度が指導の目安内（76項目）、下ろす動きが上げる動き以上の長さ |
| breath | すべての動きに呼吸の案内があり、吐く・吸うがそろう |
| program | ランダムな3000人分のメニューで、器具・痛み・時間・週のバランス・順番・休憩のルールを守る |
| numbers | 1回の動作時間・消費カロリー・重さの目安・体重の傾きが現実的な範囲 |
| simulate | 12週間の使用で負荷が実力に合わせて上がり、行ったり来たりしない |
| flow | 初回設定→トレーニング→結果→各画面が例外なく動く |
| migrate | 最初の公開版のデータを読みこめる |

調整用ツール：`tests/tools/tune.js`（お手本の自動調整）、`tests/pose.js`（関節座標の表示）
