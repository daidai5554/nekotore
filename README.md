# ねこトレ

家にある筋トレ道具・身長・体重・目標から、猫のトレーナーがメニューを組んでくれるスマホ向け筋トレアプリ（PWA）。

## ファイル
- `index.html` … アプリ本体（HTML/CSS/JS を1ファイルにまとめたもの）
- `manifest.json` / `sw.js` / `icon.svg` … ホーム画面に追加・オフライン起動用
- `dist/nekotore.html` … claude.ai Artifact 公開用（index.html からドキュメントの外枠だけ外したもの）

## スマホで使う（自分のサイトとして公開する場合）
HTTPS の静的ホスティング（GitHub Pages / Netlify / Cloudflare Pages など）にこのフォルダの中身を置くだけで動きます。
スマホで開いて「ホーム画面に追加」すると、アプリのように全画面で起動します。

## メニューの組み方（ロジックの要点）
- 週の回数で分け方を決める：2〜3回=全身、4回=上半身／下半身、5〜6回=押す・引く・脚
- 種目は「持っている道具」「痛みのある部位」「経験」で絞り込み、目的に合うものを優先
- BMI 28以上・60歳以上・膝に不安がある場合は、ジャンプ系を外す
- 目的ごとに回数・セット数・休憩を変える（筋肥大 8〜12回×3〜4 / 減量 12〜15回＋有酸素 など）
- 1回あたりの時間に収まるよう種目数を調整
- 全セットで目標の上限に届いたら次回は重さ・回数アップ、自重種目は上位の種目に昇格
- 終わったあとの「きつさ」でセット数を±1調整

## 続けるための仕組み
- 猫のなかよし度（レベル8段階）とアクセサリー解放
- 週ごとの肉球スタンプと「週連続達成」
- 気分がのらない日の「5分だけモード」
- しばらく休んでも責めずに迎えるセリフ
- 性格3種（やさしい／ツンデレ／熱血）

## RPG要素
- あなた：経験値・レベル・称号、能力4種（ちから／ふんばり／バランス／スタミナ）、実績10種
- バトル：トレーニング1回＝モンスター1体。1セットごとにダメージ（回数・重さ・能力レベルで変化、目標超えで会心）。5回に1回ボス
- にゃんだ：なかよし度＝猫のレベル（経験値ボーナス）。装備24種（あたま・かお・くび・ぶき・せなか）で強くなるが、戦闘には一切参加しない
